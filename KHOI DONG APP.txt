Cách chạy toàn bộ bằng Docker (khuyên dùng)
cd D:\Code\QUANLYKHACHHANG
copy .env.example .env
docker compose up -d --build
docker compose ps

Mở ứng dụng: http://localhost
Swagger: http://localhost/api/docs
Health check: http://localhost/api/health

Cách thủ công dành cho phát triển có hot reload
Bước 1: Bật database (Docker)
cd D:\Code\QUANLYKHACHHANG
docker compose up -d postgres
docker ps
Bước 2: Khởi động Backend (terminal 1)
cd D:\Code\QUANLYKHACHHANG\backend
.venv\Scripts\activate
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
Lần đầu (chưa có venv):

python -m venv .venv
pip install -r requirements.txt
copy .env.example .env
Bước 3: Khởi động Frontend (terminal 2)
cd D:\Code\QUANLYKHACHHANG\frontend
npm run dev -- --host 0.0.0.0 --port 3000
Lần đầu:

npm install
copy .env.example .env
Bước 4: Kiểm tra & mở app
curl http://localhost:8000/api/health
Mở trình duyệt: http://localhost:3000
